# 향후 기능 후보

다음 항목은 Build 1 계약이 아니며 클라이언트 요구가 확정된 뒤 별도 마일스톤으로 설계한다.

- 화면 선택 대상, 핑, Entity Resolver, 엔티티 ID와 `target_id`
- 주변 자원 목록과 서버의 대상 접근성 검사
- 인벤토리 연동, 정확한 수량, 가방이 찰 때까지, 목표 제작물만큼 채집
- 돌 블록, 부싯돌, 광석 등 세부 자원 구분
- 현재 제작 가능 여부 판정
- 다중 세션/동료, 재질의 TTL·상태·복원·DB 영속화
- 요청 저장/조회, SSE, 별도 버전 헤더와 운영 상태 엔드포인트
