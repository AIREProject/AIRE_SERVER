# Build 1 테스트 체크리스트

> [!WARNING]
> 레거시 문서 — 독립형 `/v1/companion/*` 계약을 설명합니다. 현행 계약은 `POST /api/v1/chat`
> (루트 `README.md`·`Contracts/` 참조). 마코 두뇌는 최상위 `companion/` 패키지로 이식됨.

- 컨텍스트 없는 나무·돌 요청이 각각 `wood`·`stone` Action을 반환한다.
- 모호한 채집은 `options: ["나무", "돌"]`을 한 번만 반환한다.
- 재질의 답변, 잘못된 답변 종료, 취소, 새 명령 교체가 동작한다.
- 따라오기, 대기, 활성 작업 중지 Action이 정확하다.
- 수량 채집, 돌 블록, 부싯돌, 광석과 다른 자원은 미지원이다.
- 일반 대화, 철 도끼 설명과 알려진 지역 세계관 설명이 동작한다.
- 성공/실패 이벤트와 나무·돌 수량 대사가 동작한다.
- 공개 요청·응답·Action에 `target` 또는 `target_id`가 없고 추가 필드는 422다.
- 구 엔드포인트, 버전 헤더, 스냅샷 검증기가 없다.
- `pytest`, Ruff, MyPy, lock 검사가 통과한다.
