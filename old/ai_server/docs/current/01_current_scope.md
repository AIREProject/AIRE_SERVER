# Build 1 현재 범위

> [!WARNING]
> 레거시 문서 — 독립형 `/v1/companion/*` 계약을 설명합니다. 현행 계약은 `POST /api/v1/chat`
> (루트 `README.md`·`Contracts/` 참조). 마코 두뇌는 최상위 `companion/` 패키지로 이식됨.

Build 1은 한 게임 세션, 동료 마코 한 명, 서버 프로세스 하나를 대상으로 한다. 공식 입력은
한국어 텍스트다.

지원 범위는 짧은 일반 대화, 철 도끼 제작법 설명, `location_id`에 근거한 안전한 지역 설명,
따라오기·대기·현재 작업 중지, 일반 나무·돌 채집이다. 나무와 돌은 자원 종류이며 특정 월드
엔티티가 아니다. 클라이언트가 가까운 자원 탐색, 경로 탐색, 접근 가능성 판단, 작업 ID와 작업
상태를 관리한다.

자원 종류가 불명확한 채집 요청은 나무와 돌 중 하나를 한 번만 묻는다. 서버 재시작 시 진행
중인 재질의가 사라지는 것은 허용한다. 설정된 Mock, OpenAI 또는 로컬 공급자는 발화 의도
분류와 대사 생성에 쓰인다. Action·재질의 선택지·오류 코드와 메시지는 결정론적으로 유지한다.
모든 대사는 저장소와 파서가 확정한 사실을 근거로 공급자가 생성하며, 공급자 호출이나 출력
검증이 실패하면 기존 결정론적 템플릿으로 복구한다.

화면 타겟, 핑, 엔티티 ID, 인벤토리 연동, 수량 지정, 세부 돌/광석 종류, 현재 제작 가능 판정은
지원하지 않는다.
